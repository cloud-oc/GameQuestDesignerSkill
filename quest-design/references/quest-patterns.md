# RPG 任务模式库

模式是分析和推导参照，不是成品配方。先确定项目约束、角色/世界矛盾、玩家承诺和可用动词，再用本库寻找风险与变体。一个任务可以组合多个模式，但应有一个清晰的主要体验。

每个模式都从八项观察：适用体验、核心循环、必要能力、常见变体、制作成本、失败方式、恢复要求、验证问题。项目能力不满足时，应改编玩家行动或将新增能力明确列为提案。

## 调查与推理

- **适用体验**：发现隐藏关系、比较矛盾证据、形成并验证判断。
- **核心循环**：提出问题 → 获取线索 → 解释/交叉验证 → 采取有后果的行动。
- **必要能力**：可观察对象、可理解反馈、知识状态或等价记录；不必默认自由推理界面。
- **常见变体**：固定线索顺序、多途径获得同一事实、允许带着不完整信息决策。
- **制作成本**：线索文本、环境状态、角色反应、地图/手册更新和遗漏补救。
- **失败方式**：跟随标记收集后由 NPC 直接公布答案；决策依据在选择之后才出现。
- **恢复要求**：关键事实可重查；错过一次性线索时有项目允许的补救或明确后果。
- **验证问题**：玩家能否在决策前说明主要证据和不确定点？

## 关系交涉

- **适用体验**：理解立场、建立信任、兑现或背离承诺。
- **核心循环**：了解诉求 → 用行动或信息建立筹码 → 表态/交换 → 获得关系反馈。
- **必要能力**：对话或行动反馈、关系/承诺状态；不必默认数值好感度。
- **常见变体**：公开说服、私下交易、替对方完成证明、维持模糊立场。
- **制作成本**：对白变体、角色状态、后续响应和配音重录。
- **失败方式**：一次无代价选项决定全部关系；所有措辞最终得到相同反应却宣称改变阵营。
- **恢复要求**：中断后保留已获得的筹码和已作出的承诺。
- **验证问题**：玩家的行动是否比选择正确台词更重要？

## 探索与发现

- **适用体验**：理解空间、通过环境线索找到地点或事实。
- **核心循环**：获得方向性信息 → 观察环境 → 修正路线 → 确认发现。
- **必要能力**：可达空间、环境区别、方向反馈；精确地图标记不是必需能力。
- **常见变体**：地标导航、声音/痕迹追踪、分区搜索、从高处规划路线。
- **制作成本**：关卡可读性、地标、误入回引、可访问性替代提示。
- **失败方式**：未发现线索就显示终点；扩大地图却没有新的判断。
- **恢复要求**：离开后保留已确认线索；必要信息不只依赖短暂颜色或声音。
- **验证问题**：玩家走对时能否解释依据，而不是只说“标记在那里”？

## 潜入与规避

- **适用体验**：观察规律、控制暴露风险、选择路线或时机。
- **核心循环**：侦察 → 规划 → 执行 → 对暴露作出反应。
- **必要能力**：可理解的发现规则、替代路线、失败或警戒反馈。
- **常见变体**：完全规避、有限暴露、伪装、制造干扰、潜入转战斗。
- **制作成本**：AI 状态、路线、动画、警戒 UI、失败恢复和组合测试。
- **失败方式**：发现规则不可读；被发现后只剩读档；只有一条正确路线。
- **恢复要求**：明确警戒衰减、失败、检查点和任务继续方式。
- **验证问题**：玩家能否从反馈判断为何暴露以及下一次如何改进？

## 护送与保护

- **适用体验**：承担责任、分配注意力、在移动或压力中保护对象。
- **核心循环**：确认对象需求 → 清理/选择路线 → 处理威胁 → 到达或守住目标。
- **必要能力**：对象可用性、跟随/移动/替代表达、失败与重试规则。
- **常见变体**：实时护送、分段会合、预先处理路线、固定地点防守。
- **制作成本**：导航 AI、卡位处理、速度协调、对白、重入和场景切换。
- **失败方式**：对象速度持续与玩家冲突；对象卡住却没有恢复；项目不支持护送仍伪造能力。
- **恢复要求**：定义对象消失、死亡、离开加载范围和读档后的检查点。
- **验证问题**：保护对象带来决策，还是只把移动时间拉长？

## 战斗狩猎

- **适用体验**：追踪目标、准备克制手段、在战斗中验证前期信息。
- **核心循环**：识别威胁 → 获取准备信息/资源 → 追踪 → 对抗 → 处理结果。
- **必要能力**：可靠的目标身份、战斗结果事件或持久状态、重复击杀语义。
- **常见变体**：单目标追猎、多目标清剿、非致命制服、环境削弱。
- **制作成本**：敌人、遭遇、战斗空间、难度适配和战后世界状态。
- **失败方式**：接取前已击杀导致无法完成；普通战斗与故事承诺没有联系。
- **恢复要求**：处理提前击杀、目标刷新、失败重试和击杀事件重复。
- **验证问题**：准备与追踪是否真正改变对抗方式或理解？

## 解谜与机关

- **适用体验**：理解规则、形成假设、通过操作证明理解。
- **核心循环**：观察规则 → 尝试 → 获得诊断反馈 → 修正 → 解开。
- **必要能力**：稳定规则、可撤销或可恢复状态、失败反馈。
- **常见变体**：空间、顺序、逻辑、资源分配、多人协作。
- **制作成本**：机关状态、提示层级、重置、存档和可访问性。
- **失败方式**：无提示试遍组合；NPC 在玩家思考前给答案；错误状态不可恢复。
- **恢复要求**：定义重置范围和离开/读档后的机关状态。
- **验证问题**：成功来自理解规则，还是偶然操作？

## 救援与防守

- **适用体验**：时间或资源压力下确定优先级，守住人物、地点或进度。
- **核心循环**：识别威胁 → 布置/选择优先级 → 应对波次或事件 → 结算损失。
- **必要能力**：威胁反馈、守护对象状态、成功/失败阈值。
- **常见变体**：定时防守、疏散、多点取舍、允许部分损失。
- **制作成本**：遭遇编排、AI、场景变化、失败分支和性能峰值。
- **失败方式**：威胁来自屏外且无预警；所有对象都必须无伤导致单一解法。
- **恢复要求**：明确重试检查点、部分失败后果和中断时计时语义。
- **验证问题**：压力是否促成有意义的取舍，而不是单纯堆敌人？

## 收集与制作

- **适用体验**：规划来源、理解材料用途、把资源转化为新能力或世界变化。
- **核心循环**：识别需求 → 选择来源 → 获取/替代 → 制作或交付 → 使用成果。
- **必要能力**：物品身份、计数范围、消耗与结算规则。
- **常见变体**：固定材料、替代配方、品质权衡、共同贡献。
- **制作成本**：物品、掉落/采集点、UI、经济平衡和本地化。
- **失败方式**：只增加数量没有选择；“当前持有”与“接取后获取”混淆。
- **恢复要求**：处理提前持有、交付后断线、材料消耗和重复提交。
- **验证问题**：收集过程是否产生路线、来源或用途决策？

## 多任务共享世界

- **适用体验**：让任务影响同一人物、地点和世界事实，形成连续世界感。
- **核心循环**：读取世界事实 → 执行局部任务 → 写入变化 → 其他内容响应。
- **必要能力**：世界状态所有权、共享对象冲突规则、内容关闭/替代反馈。
- **常见变体**：任意顺序支线、互斥入口、章节关闭、替代交付人。
- **制作成本**：状态组合、对白变体、旧存档、跨任务回归和资产生命周期。
- **失败方式**：任务 A 移除 NPC 后任务 B 永久卡死；复制 NPC 掩盖冲突。
- **恢复要求**：定义共享对象不可用、版本变化和场景重载后的响应。
- **验证问题**：每种可达顺序都能到合法终态，并给玩家可理解的反馈吗？

## 组合与收敛

组合模式时，写明主要体验和辅助模式。例如“调查为主、潜入为获取途径”比同时宣称调查/潜入/战斗/解谜四个核心更可执行。删除辅助模式后若玩家承诺仍成立，应优先把它作为可缩减范围。
