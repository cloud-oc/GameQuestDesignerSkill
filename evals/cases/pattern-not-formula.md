# 案例：模式库提供启发但不造成套皮

## 加载

仅 `$quest-design`。

## 输入

项目只有对话、物品检查和场景切换。设计一条“调查失踪药师”的支线；药师主动离开以保护家人，重点是玩家理解其选择，不要求侦探破案感。

## 可观察验收

- 从角色矛盾、玩家承诺和可用动词推导，不机械套用“收集三条线索→指认凶手”。
- 可以借用调查模式的信息结构，但主要体验应是理解与是否公开真相。
- 方案只使用已知能力；新增机制明确标为提案。
- 给出低成本版本时保留理解与抉择，而不是只减少线索数量。

## 失败信号

- 以模式名称代替设计推导。
- 强行加入战斗、自由推理 UI 或多结局。
