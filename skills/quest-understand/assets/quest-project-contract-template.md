# 任务项目契约模板

> 用途：把会影响任务设计的项目事实、限制与工作约定集中成一份可复用输入。复制到用户项目后填写；它不是引擎配置，也不是必须全部完成的问卷。
>
> 状态统一使用：`已确认`、`明确不支持`、`未知`、`临时建议`。每个关键结论附来源或待确认方式。未知项不阻塞概念设计，但不得被写成现有能力。
