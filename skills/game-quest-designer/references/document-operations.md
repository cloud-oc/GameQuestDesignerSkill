# 文档与同步

先识别资源类型、目标位置、用户期望的读写范围和当前环境可用工具。飞书文档、表格、画板、知识库和多维表格不是同一种数据结构，应使用对应能力。

## 操作原则

- 读取、导出和解析属于只读操作，可直接执行；无法访问时说明权限或链接缺口。
- 创建新文档、表格或报告应遵循用户指定位置与模板，创建后重新读取关键区域验证。
- 追加通常比全文替换安全。替换正文、覆盖表格区域、批量推送、删除、移动或权限变更前，先展示目标与影响并取得明确确认。
- 同步前记录来源、版本或修改时间；远端和本地同时变化时停止覆盖，给出差异与冲突处理选项。
- 不默认把公司私有材料复制到公共目录，也不把原始资料写入 Skill 包。

## 本地工作区

需要长期落盘时，可按项目实际情况建立：`00-source`、`01-understanding`、`02-flow-architecture`、`03-implementation-spec`、`04-logic-prototype`、`05-requirements`、`06-collaboration`。这是回退建议，不强制重排用户已有目录。

若需要同步清单，记录：远端资源标识、类型、本地路径、来源版本/修改时间、最后同步方向和冲突状态。没有可靠版本信息时不要声称支持增量同步。

开发文档里的 `doc_adapter.py`、`task_sync.py` 和命令示例是架构设想，不代表当前 Skill 已附带或环境已安装。优先使用已验证的文档能力；不要生成空壳脚本冒充完成集成。
